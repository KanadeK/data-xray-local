# Benchmark

The benchmark is generated by `python scripts/benchmark.py`. It copies the deterministic CC0
sample export into a repository-local temporary corpus, performs one warm-up, runs five measured
scans with `no_network=True`, writes `reports/benchmark.json`, and removes the corpus.

## v0.1.0 result

Run date: 2026-07-23

| Field | Result |
|---|---:|
| OS | Windows 11 `10.0.26200` |
| Python | 3.12.13 |
| Processor string | Unavailable from the managed runtime |
| Corpus | 50 copies / 450 files / 1,547,000 bytes |
| Measured runs | 5 after 1 warm-up |
| Median | 0.5636 s |
| Minimum / maximum | 0.4132 s / 0.6587 s |
| Median throughput | 798.4 files/s |
| Findings / repeat groups | 1,450 / 20 |
| Network guard | Enabled |

The sample-size acceptance target is “complete in a reasonable interactive time.” The measured
450-file corpus completed below 0.7 seconds in every measured run. Format composition is unusually
small and regular, so the file-per-second number must not be extrapolated to large images, complex
workbooks, damaged containers, slow disks, or hostile inputs.

The raw machine-readable result is generated at `reports/benchmark.json`; it is intentionally not
committed because platform measurements are evidence for the release note, not deterministic
source data.
