# Security policy

## Supported versions

Security fixes are provided for the latest tagged release.

## Reporting a vulnerability

Do not open a public issue containing exploit details or sensitive sample files. Use GitHub's
private vulnerability reporting for this repository. Include a minimal synthetic reproducer,
affected version, impact, and suggested mitigation when possible.

You should receive an acknowledgement within seven days. A coordinated disclosure timeline will
be agreed after triage.

## Security boundary

Data XRay Local is a heuristic review aid, not a compliance certification or malware scanner. It
does not upload source files, and its report deliberately masks matches. A clean scan cannot prove
that a folder is safe to publish. Review the generated report and original files before disclosure.
